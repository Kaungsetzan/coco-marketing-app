# Coco – Marketing App for Small Businesses

Coco is a Flutter prototype that helps small businesses, such as cafés, create social media posts and promote them to nearby customers, without needing marketing know-how.

I built it in my third semester while learning Flutter.

## What the app does

1. **Sign up / log in** with email and password (Firebase Authentication).
2. **Pick a content idea** from a swipeable set of category cards on the home screen.
3. **Capture content** with the in-app camera or pick a photo from the gallery.
4. **Preview** the post before publishing.
5. **Publish**: describe the content (who is in the post, what they are doing, the feeling at the end) and choose where to post it: Facebook or Instagram.
6. **Boost** a post: choose the radius, target audience (e.g. café lovers, students, tourists, foodies), daily budget and campaign duration.
7. **Estimate reach**: review the expected reach, total fees and payment method before activating the boost.

## Tech stack

- **Flutter / Dart** (SDK ^3.10)
- **Firebase Core + Firebase Auth** for user accounts
- **camera** and **image_picker** for capturing and selecting photos

## How to run the app

### 1. Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (Dart 3.10 or newer). Check with:
  ```bash
  flutter --version
  flutter doctor
  ```
- For Android: Android Studio with an emulator, or a real Android phone with USB debugging on.
- For iOS (macOS only): Xcode and CocoaPods, with a simulator or a real iPhone.

### 2. Clone and install dependencies

```bash
git clone https://github.com/Kaungsetzan/coco-marketing-app.git
cd coco-marketing-app
flutter pub get
```

### 3. Run it

Start an emulator/simulator (or plug in a phone), then:

```bash
flutter devices      # check that a device is listed
flutter run          # run on the connected device
```

To pick a specific device:

```bash
flutter run -d <device-id>
```

The repo already includes a Firebase config for the demo project, so the app runs as it is. Create an account on the sign-up screen to get in.

> **Tip:** The camera works best on a real phone. On an emulator, use the gallery option instead.

### Using your own Firebase project (optional)

If you want to connect the app to your own Firebase project:

1. Create a project in the [Firebase console](https://console.firebase.google.com/) and enable **Authentication → Email/Password**.
2. Install the CLIs and log in:
   ```bash
   npm install -g firebase-tools
   dart pub global activate flutterfire_cli
   firebase login
   ```
3. In the project folder, run:
   ```bash
   flutterfire configure
   ```
   This regenerates `lib/firebase_options.dart`, `android/app/google-services.json` and `ios/Runner/GoogleService-Info.plist` for your project.

## Current status

This is a **UI prototype**. Login and sign-up are connected to Firebase. Publishing to Facebook/Instagram, boosting and payment are designed as screens but not yet connected to real APIs, and saving drafts to Firestore is still a placeholder.
